# Roadmap

## Current

The repository is at v0.9.0: evaluation cases, deterministic offline evaluation,
input/output guardrails, Supervisor integration, execution tracing, and the v0.8.4
Commercial/RAG behavior are present. Historical version labels below reflect the
project evolution represented by the repository history and release notes.

v0.1 basic LLM integration; v0.2 UI and execution improvements; v0.3 gas business
case and deterministic tooling; v0.5 scenario analysis; v0.6 RAG; v0.7 agent
foundations; v0.8 multi-agent; v0.8.4 frontend and execution UX; v0.9 evaluation and
guardrails.

## Planned, not implemented

These are directions rather than commitments:

- **v1.0 Commercial MVP:** product-oriented UX, deployable demonstration,
  installation documentation, and a durable execution/conversation model.
- **v1.1 Enterprise backend:** API layer, durable persistence, and decoupled
  services.
- **v1.2 Integrations:** demand forecasts, market prices, procurement/trading,
  CRM, and contract repositories.
- **v1.3 Enterprise security:** SSO/OIDC, RBAC, document access controls, audit,
  tenant isolation, secrets and retention.
- **v1.4–v1.7:** model routing, enterprise knowledge platform, observability/FinOps,
  and multi-company configuration.
- **v2.0:** SaaS or enterprise product packaging.

None of these future layers currently exists in the repository. They should be
introduced only through deliberate decisions and compatible migrations.
