# Roadmap

## Current

The repository has completed the v1.0 Commercial MVP implementation and release-
candidate validation. v0.9 established evaluation cases, deterministic offline
evaluation, input/output guardrails, Supervisor integration and execution tracing;
v1.0 adds the validated Commercial shell, Executive Result, canonical demos and
installation/demo readiness. The final v1.0.0 release tag has not yet been created.
Historical version labels below reflect the project evolution represented by the
repository history and release notes.

v0.1 basic LLM integration; v0.2 UI and execution improvements; v0.3 gas business
case and deterministic tooling; v0.5 scenario analysis; v0.6 RAG; v0.7 agent
foundations; v0.8 multi-agent; v0.8.4 frontend and execution UX; v0.9 evaluation and
guardrails.

## Completed

- **v1.0 Commercial MVP:** implemented and release-candidate validated across the
  four canonical Business demos.

## Planned, not implemented

These are directions rather than commitments:

- **v1.1 Enterprise backend:** API layer, durable persistence, and decoupled
  services.
- **v1.2 Integrations:** demand forecasts, market prices, procurement/trading,
  CRM, and contract repositories.
- **v1.3 Enterprise security:** SSO/OIDC, RBAC, document access controls, audit,
  tenant isolation, secrets and retention.
- **v1.4 AI Gateway / Model Router:** model routing.
- **v1.5 Knowledge Platform:** enterprise knowledge platform.
- **v1.6 Observability + FinOps:** enterprise observability and FinOps.
- **v1.7 Multi-company configuration:** multi-company configuration.
- **v2.0:** SaaS or enterprise product packaging.

None of these future layers currently exists in the repository. They should be
introduced only through deliberate decisions and compatible migrations.
